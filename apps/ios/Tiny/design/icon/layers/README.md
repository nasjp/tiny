# Icon Composer steps (manual)
1. In Icon Composer.app choose New → iOS and import bg.png / glyph.png / dot.png as 3 groups, back to front
2. Finish in Default (Light) → for Dark/Clear/Tinted adjust only the background color (foreground is shared)
3. If the glyph's details get crushed, turn off Specular for that group
4. Export the .icon and assign it to the Xcode project's AppIcon
